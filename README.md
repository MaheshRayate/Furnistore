🛋️ **FurniStore – Furniture E-Commerce Application**

FurniStore is a full-stack e-commerce web application built for browsing and purchasing furniture products with a smooth, secure, and responsive user experience.

The application is developed using Next.js (App Router) and React 19, leveraging server-side rendering and modern routing for performance and SEO. User authentication and session management are handled via Clerk, while Prisma ORM with PostgreSQL manages products, carts, orders, and user data.

Secure online payments are implemented using Stripe Embedded Checkout, enabling seamless checkout flows. Supabase is used for backend services and integrations. The UI is built with Tailwind CSS and Radix UI, ensuring accessibility, consistency, and responsiveness across devices.

Additional features include product carousels, debounced search, theme switching, toast notifications, and robust form validation using Zod.

🚀 **Tech Stack**

**Frontend: Next.js 16, React 19, Tailwind CSS, ShadCN UI**

**Backend: Next.js API Routes, Prisma ORM**

**Database: PostgreSQL**

**Authentication: Clerk**

**Payments: Stripe Embedded Checkout**

**Utilities & Tools: Axios, Zod, Supabase**
